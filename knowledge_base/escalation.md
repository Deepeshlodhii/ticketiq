# Escalation Policy

Tickets should be escalated to a human support agent when the issue cannot be safely resolved automatically.

Escalation is appropriate for unresolved account access problems, disputed financial transactions, repeated technical failures, or situations requiring manual investigation.

High-urgency tickets should receive priority during escalation.

The agent should provide the reason for escalation and include relevant ticket information.

The agent should not claim that a refund, account change, or other manual action has been completed unless the corresponding tool or human support process confirms it.
