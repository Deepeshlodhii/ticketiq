# Account Access Troubleshooting

Customers who cannot log in should first verify their email address and password.

If a password has been forgotten, the customer can use the password reset flow.

If a verification code is not received, the customer should check their spam folder and request a new code.

Locked accounts may require identity verification before access can be restored.

Changes to account email or phone number may require additional verification.

For account-specific issues, support may use the check_account_status tool when a customer ID is available.
